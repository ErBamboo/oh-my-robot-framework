# omhost 测试用例

本目录每个 `*.json` 是一个测试用例，omhost 启动时自动加载；新增文件后
在页面“测试矩阵”点“刷新”即可运行。工程内的附加用例可放在
`cfg/omhost/testcases/`，或用 `omhost --test-dir <dir>` 指定。

用例的完整步骤类型与字段说明见 [`../README.md`](../README.md) 的“测试台”一节。

约定：

- `id` 在全部用例目录内唯一，只允许字母、数字、`_`、`.`、`-`。
- `steps` 按顺序执行；角色由步骤类型推导（继电器 / 被测板串口 / J-Link）。
- 依赖尚未实现能力的用例标 `"blocked": "OMR-49"`，页面会禁用运行。
- `layout` / `payloadFile` 路径先按用例目录、再按仓库根、最后按当前目录解析。
- `output` / `image` 只写运行目录 `~/.omhost/runs/<run-id>/`，不得使用绝对路径或 `..`。
- 硬件用例不要假设串口号或 J-Link 序列号，运行前在页面“资源”里分配。
